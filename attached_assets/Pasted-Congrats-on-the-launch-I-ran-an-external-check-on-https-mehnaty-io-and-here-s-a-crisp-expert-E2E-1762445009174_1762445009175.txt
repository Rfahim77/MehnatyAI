5) Security & reliability (server)

// Express hardening
app.disable('x-powered-by');
app.use(helmet({ /* add CSP below */ }));
app.use(rateLimit({ windowMs: 60_000, max: 60 }));
// CSP: limit connect-src to your API + analytics; block framing; set HSTS via proxy.

	•	CSP with strict script-src, connect-src to your LLM API.
	•	Timeouts & retries on all AI calls; friendly Arabic error messages.
	•	Upload safety: 5 MB limit, extension + magic-number checks (PDF/DOCX/JPG/PNG/WEBP), OCR in a worker thread.
	•	Prompt-injection guard: wrap user docs (JD/CV) in a neutralizing envelope and never follow embedded instructions.
	•	Validation: parse to a strict JSON schema (Zod), block invented degrees/dates, insert metric placeholders like “(أضف رقمًا تقريبيًا)”.
