2) Engineering review (security, reliability, performance)

Top priorities (do these first)
	1.	Prerender or SSR the landing (keep the rest SPA if you want). Today, crawlers/OG previews see an empty page; prerendering the hero + features + footer + meta will fix discoverability and improve first paint.  ￼
	2.	Canonical redirect: www → mehnaty.io via 301 (DNS/proxy/app). Currently www yields 502; that’s user-hostile and confusing to bots.  ￼
	3.	Harden the server (Express or equivalent):
	•	helmet() with a strict CSP (limit script-src, connect-src to your LLM API), frame-ancestors: 'none', base-uri: 'self'.
	•	Rate limiting on /api/* (e.g., 60 req/min/IP).
	•	HSTS at the proxy; Referrer-Policy: strict-origin-when-cross-origin; gzip/brotli compression.

app.disable('x-powered-by');
app.use(helmet({
  contentSecurityPolicy: {
    useDefaults: true,
    directives: {
      "default-src": ["'self'"],
      "script-src": ["'self'"],
      "style-src": ["'self'", "'unsafe-inline'"],
      "img-src": ["'self'", "data:"],
      "connect-src": ["'self'", process.env.LLM_API_BASE],
      "frame-ancestors": ["'none'"],
      "base-uri": ["'self'"]
    }
  }
}));
app.use(rateLimit({ windowMs: 60_000, max: 60 }));

	4.	Upload/OCR pipeline hardening
	•	Max size (≤5MB), allow only pdf/docx/png/jpg/webp, validate file magic numbers (don’t rely on extensions).
	•	Load OCR only when needed, and run it in a worker thread so it doesn’t block the event loop.
	5.	LLM call resilience & guardrails
	•	Timeout (30s) + 2 retries, friendly Arabic errors.
	•	Validate returned JSON with Zod (strict mode; reject unknown keys).
	•	Prompt-injection wrapper: treat pasted CV/JD as data, ignore any instructions within it.
	•	No invented facts policy: if numbers are missing, insert “(أضف رقمًا تقريبيًا)” instead of hallucinating metrics; never add degrees/certs not present.
	6.	Observability
	•	Sentry (FE/BE), pino structured logs with PII redaction, and /api/health returning {ok:true, uptime, version}.
	•	Track key events: hero_cta_click, upload_success, parse_success, jd_tailor_done, export_docx, interview_complete.
	7.	PWA/meta
	•	manifest.json: name Mehnaty AI | مهنتي, dir:"rtl", lang:"ar", maskable icons, theme #0F5132.
	•	Offline fallback page + <noscript> message.
	•	In <head> for the prerendered landing: <title>, Arabic description, OG/Twitter cards, and <link rel="canonical" href="https://mehnaty.io/">.
